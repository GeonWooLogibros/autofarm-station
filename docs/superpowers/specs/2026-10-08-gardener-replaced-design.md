# 오토팜 스테이션: 설계 문서

작성일: 2026-10-08

이 게임은 작업용 제목 「정원사는 대체되었다」에서 「오토팜 스테이션」으로 2026-10-12에 이름을 바꾸었다. 아래 본문의 나머지는 작성 당시 그대로 둔다.

## 1. 목표

스팀 게임 「농부는 대체되었다」의 핵심 구조를 웹 게임으로 다시 만듭니다. 플레이어는 우주정거장 온실에서 드론을 파이썬 문법으로 코딩하여 화분 재배를 자동화하고, 수확물로 새 문법과 작물, 선반을 해금합니다. 마지막 해금 항목인 "완전 자동화"를 구입하면 엔딩을 보여 줍니다.

- **대상:** 파이썬을 조금 아는 사람과 코딩이 처음인 사람을 모두 대상으로 합니다. 기본 설정에서는 해금할 때마다 안내와 예제를 보여 주고, 설정에서 안내를 끌 수 있습니다.
- **분량:** 엔딩까지 1~2시간을 목표로 합니다.
- **환경:** PC 브라우저와 키보드를 기준으로 합니다. 설치 없이 HTML 파일 하나로 실행할 수 있어야 합니다.
- **그림:** 코드모스 에셋 창고의 그림을 사용하고, 필요하면 수정합니다. 창고에 없는 그림은 같은 평면 벡터 그림체로 새로 그립니다.

### 성공 기준

1. 코딩이 처음인 사람이 안내만 읽고 `while` 반복으로 데이지를 자동 수확하는 단계까지 스스로 도달할 수 있습니다.
2. 무한 반복 코드를 실행해도 화면이 멈추지 않고, 정지 버튼이 즉시 동작합니다.
3. 오류가 발생하면 해당 줄이 강조되고, 원인을 한국어 문장으로 알려 줍니다.
4. 브라우저를 닫았다가 다시 열어도 코드, 자원, 해금 상태, 선반 상태가 그대로 남아 있습니다.

### 1차 범위에서 제외하는 것

- 드론 여러 대를 동시에 실행하는 기능
- 기록 경쟁(목표 달성 시간 순위)
- 모바일 터치 입력에 맞춘 편집기
- 게임을 닫은 동안의 진행(오프라인 진행)
- 코드 파일 여러 개와 `import`

## 2. 화면 구성

화면은 좌우 두 영역으로 나눕니다.

### 왼쪽: 코드 편집기

- 편집기는 파일 하나만 다룹니다. 파이썬 문법 강조와 자동 들여쓰기를 지원합니다.
- 상단에 실행, 정지, 한 단계 실행 버튼이 있습니다.
- 프로그램이 실행되는 동안에는 지금 실행 중인 줄을 강조합니다.
- 편집기 아래에 출력 영역이 있으며, `print()`의 결과와 오류 안내를 여기에 표시합니다.

### 오른쪽: 온실

- 선반을 정면에서 본 격자로 그립니다. 칸마다 화분이 하나씩 놓여 있고, 드론이 칸 사이를 날아다닙니다.
- 식물은 성장 단계에 따라 그림이 바뀝니다(씨앗, 1단계, 2단계, 3단계).
- 물을 준 화분은 흙 색이 짙어지고, 수분이 줄어들면 다시 밝아집니다.
- 해바라기의 꽃잎 수와 과일 상자의 무게는 그림 위에 숫자로 직접 표시합니다.
- 드론이 수확하면 수확물이 화면 아래의 트럭으로 날아가고, 트럭 옆 화물칸에 자원별 보유량을 상자와 숫자로 표시합니다.

### 해금 화면

정거장 설비 지도 형태로 해금 항목을 배치합니다. 항목마다 이름, 비용, 선행 항목을 보여 주며, 비용을 낼 수 있는 항목은 강조합니다.

### 안내와 설명서

- 항목을 해금하면 인트 캐릭터가 말풍선으로 설명 2~3문장과 예제 코드, 스스로 해 볼 목표 하나를 보여 줍니다.
- 예제 코드는 복사 버튼으로 가져갑니다. 플레이어가 작성한 코드를 덮어쓰지 않습니다.
- 설명서 화면에서는 해금한 항목의 설명과 사용할 수 있는 함수 목록을 다시 볼 수 있습니다.
- 설정에서 안내를 끄면 말풍선은 나타나지 않고, 설명서에서만 내용을 볼 수 있습니다.

### 문구 규칙

버튼은 "실행하기", "해금하기"처럼 "~하기" 형태나 명사형으로 쓰고, 설명과 안내는 합니다체로 씁니다.

## 3. 코드 언어

파이썬 문법의 일부를 직접 해석하는 실행기를 만듭니다. 실제 파이썬 실행 환경(Pyodide)은 용량이 크고 한 줄씩 멈추면서 실행하기 어렵기 때문에 사용하지 않습니다.

### 지원하는 문법

| 문법 | 해금 항목 |
|---|---|
| 함수 호출, 주석, `pass` | 처음부터 사용 가능 |
| `while`, `break`, `continue`, `True`, `False` | 반복 |
| `if`, `elif`, `else`, 비교 연산자, `and`, `or`, `not`, `None` | 조건문 |
| 변수 대입, `+=` 등 복합 대입, 산술 연산자(`+ - * / // % **`) | 변수 |
| `def`, `return`, `global` | 함수 |
| `for ... in`, `range()`(인자 1~3개) | for 반복 |
| 리스트, 튜플, 인덱싱, `len()`, `append()`, `pop()`, `insert()`, `remove()`, `in`, `min()`, `max()` | 리스트 |
| 딕셔너리, 키 조회와 대입, `in`, 키 순회 | 딕셔너리 |

문자열은 `print()`에 넘기는 용도로만 지원합니다. 클래스, `import`, 예외 처리, 람다, 컴프리헨션, 슬라이싱은 지원하지 않습니다.

잠겨 있는 문법이나 함수를 사용하면 실행하기 전에 "`if`는 아직 해금하지 않았습니다. 해금 화면에서 '조건문'을 해금하면 사용할 수 있습니다."와 같이 알려 줍니다.

### 드론 함수

방향 상수는 `Right`, `Left`, `Up`, `Down`이고, 작물 상수는 `Daisy`, `Strawberry`, `Tulip`, `Sunflower`, `Tomato`, `Crate`입니다. 자원 상수는 작물 상수에 `Power`, `Coin`, `Water`를 더한 것입니다.

| 함수 | 동작 | 종류 |
|---|---|---|
| `move(방향)` | 한 칸 이동합니다. 선반 끝을 넘어가면 반대편으로 이어집니다. | 동작 |
| `harvest()` | 현재 칸을 수확합니다. 수확했으면 `True`를 돌려줍니다. | 동작 |
| `plant(작물)` | 현재 칸에 작물을 심습니다. 비용이 부족하거나 칸이 차 있으면 `False`를 돌려줍니다. | 동작 |
| `water()` | 물탱크의 물 1을 써서 현재 칸의 수분을 0.25 올립니다. | 동작 |
| `swap(방향)` | 현재 칸과 이웃 칸의 내용물을 서로 바꿉니다. | 동작 |
| `can_harvest()` | 현재 칸의 작물이 다 자랐는지 돌려줍니다. | 감지 |
| `get_plant_type()` | 현재 칸의 작물 상수를 돌려주고, 비어 있으면 `None`을 돌려줍니다. | 감지 |
| `get_water()` | 현재 칸의 수분(0~1)을 돌려줍니다. | 감지 |
| `measure()`, `measure(방향)` | 해바라기의 꽃잎 수 또는 상자의 무게를 돌려줍니다. 방향을 주면 이웃 칸을 잽니다. | 감지 |
| `get_pos_x()`, `get_pos_y()` | 드론의 위치를 돌려줍니다. 왼쪽 아래 칸이 (0, 0)입니다. | 감지 |
| `get_world_size()` | 선반 한 변의 칸 수를 돌려줍니다. | 감지 |
| `num_items(자원)` | 자원 보유량을 돌려줍니다. | 감지 |
| `print(값)` | 출력 영역에 값을 표시합니다. | 감지 |

함수는 관련된 항목을 해금해야 사용할 수 있습니다. 예를 들어 `water()`는 "물주기" 항목을, `swap()`은 "과일 상자" 항목을 해금해야 합니다.

### 실행 시간 규칙

- 동작 함수는 200틱, 감지 함수와 그 밖의 문장은 1틱을 사용합니다.
- 드론은 1초에 400틱을 처리하는 속도로 시작합니다. 따라서 동작 하나에 0.5초가 걸립니다. 속도 강화를 해금하면 처리량이 늘어납니다.
- 실행기는 화면 한 프레임마다 주어진 틱만큼만 실행하고 멈췄다가 다음 프레임에 이어서 실행합니다. 이 구조 때문에 무한 반복 코드에서도 화면이 멈추지 않습니다.
- 한 단계 실행 버튼은 문장 하나를 실행하고 멈춥니다.
- 동작에 걸리는 시간은 프로그램이 아니라 드론에게 남습니다. 프로그램이 끝나거나, 정지하거나, 다시 실행하거나, 한 단계씩 실행해도 드론은 앞서 한 동작의 시간을 다 채운 뒤에야 다음 문장을 실행합니다. 드론이 동작을 끝내기 전에 누른 한 단계 실행은 프로그램을 멈추기만 하고 문장은 실행하지 않습니다.
- 멈춘 동안 코드를 고쳤다면 실행하기와 한 단계 실행하기는 이어서 실행하지 않고 고친 코드로 처음부터 시작합니다.
- 한 번에 다룰 수 있는 값의 수에는 한도가 있습니다. `range()`가 만드는 값과 `+`로 이어 붙인 리스트와 문자열은 10,000개까지이고, 출력 한 줄은 2,000자까지만 표시합니다.

## 4. 온실 규칙

### 선반

선반은 1칸에서 시작하여 가로 3칸, 3×3, 4×4, 6×6 순서로 넓어집니다. 넓히는 단계마다 해금 항목이 하나씩 있습니다.

### 물

- 물탱크는 10초마다 물 1이 자동으로 채워지며, 최대 저장량은 해금으로 늘어납니다.
- 칸의 수분은 0에서 1 사이이고, 작물이 자라는 속도는 `1 + 4 × 수분`배가 됩니다.
- 수분은 1초마다 현재 값의 1%씩 줄어듭니다.

### 작물

아래 수치는 초기값이며, 플레이해 본 뒤에 조정합니다.

| 작물 | 심는 비용 | 성장 시간 | 수확물 | 특수 규칙 |
|---|---|---|---|---|
| 데이지 | 없음 | 2초 | 데이지 1 | 빈 화분에 저절로 핍니다. |
| 딸기 | 데이지 1 | 6초 | 딸기 1 | 없음 |
| 튤립 | 데이지 2 | 8초 | 튤립 3 | 상하좌우 이웃에 튤립이 하나 있을 때마다 성장 시간이 2배가 됩니다. |
| 해바라기 | 딸기 1 | 6초 | 전력 1 | 아래 "해바라기" 참고 |
| 토마토 | 튤립 1 | 4초 | 토마토 1 | 아래 "토마토" 참고 |
| 과일 상자 | 토마토 1 | 즉시 | 코인 1 | 아래 "과일 상자" 참고 |

다 자라지 않은 작물을 수확하면 작물만 사라지고 수확물은 얻지 못합니다. 다만 데이지는 예외로, 다 자라지 않았으면 수확되지 않고 그대로 남습니다. 조건문을 해금하기 전에는 `can_harvest()`로 확인할 방법이 없기 때문입니다. 튤립, 토마토, 과일 상자의 이웃 판정에서는 선반 끝이 반대편으로 이어지는 것을 고려하지 않습니다.

**해바라기.** 해바라기는 심을 때 꽃잎 수가 7에서 15 사이로 정해집니다. 선반에 다 자란 해바라기가 10송이 이상 있고, 그중 꽃잎이 가장 많은 해바라기를 수확하면 전력을 8배로 얻습니다. 전력을 보유하고 있으면 드론의 속도가 2배가 되고, 동작을 30번 할 때마다 전력 1을 소모합니다.

**토마토.** 토마토는 다 자라는 순간에 20% 확률로 시듭니다. 시든 토마토는 수확할 수 없고, 그 칸에 다시 `plant()`를 하면 새로 심은 작물로 교체됩니다. 익은 토마토를 수확하면, 그 칸을 포함하면서 익은 토마토로만 채워진 가장 큰 정사각형(n×n)을 찾아 전체를 한꺼번에 수확하고 토마토 n³개를 얻습니다. n은 최대 6입니다.

**과일 상자.** 과일 상자는 놓을 때 무게가 0에서 9 사이로 정해지고, 무게에 따라 상자 그림과 숫자가 달라집니다. 상자 하나는 오른쪽과 위쪽 이웃 상자가 자신보다 무겁거나 같고, 왼쪽과 아래쪽 이웃 상자가 자신보다 가볍거나 같을 때 "정리된" 상태입니다. 이웃 칸에 상자가 없으면 그 방향의 조건은 충족한 것으로 봅니다. 정리된 상자를 수확하면 상하좌우로 연결된 정리된 상자를 모두 출하하고, 출하한 개수의 제곱만큼 코인을 얻습니다. 정리되지 않은 상자를 수확하면 그 상자 하나만 출하하고 코인 1을 얻습니다. 정리되지 않은 상자는 테두리를 붉게 표시합니다.

## 5. 해금 트리

아래 순서로 진행하도록 선행 관계를 정합니다. 비용은 모범 코드로 엔딩까지 실행해 본 결과(약 60분)에 맞추어 조정한 값입니다.

| 9 | 함수 | 딸기 100, 데이지 100 | `def` |
| 10 | 튤립 | 딸기 200 | 튤립 |

| 20 | 수확량 강화(데이지, 딸기, 튤립 각각) | 해당 작물 200 | 해당 작물의 수확량 2배. 그 작물을 심을 수 있게 된 뒤에는 언제든지 구입할 수 있습니다. |
| 21 | 완전 자동화 | 코인 2,500 | 엔딩 |

선반 확장은 앞 단계를 해금해야 다음 단계를 구입할 수 있습니다(확장 1 → 2 → 3 → 4). 선반은 넓어지기만 하고 줄어들지 않습니다.

엔딩 화면에는 시작부터 걸린 시간을 표시합니다. 엔딩을 본 뒤에도 계속 플레이할 수 있습니다.

## 6. 그림과 소리

### 코드모스 에셋 창고에서 가져오는 것

| 에셋 묶음 | 사용할 그림 | 수정 내용 |
|---|---|---|
| 수학 P352 | 드론 4색(빈 상태, 짐 실은 상태) | 한 가지 색만 사용하고, 프로펠러 회전과 위아래 흔들림을 추가합니다. |
| 수학 P950 | 식물 5종 3단계, 씨앗, 화분, 물방울, 호스 | 화분 크기를 선반 칸에 맞추고, 시든 토마토 그림을 추가로 만듭니다. |
| 수학 P439 | 과일 8종, 과일 상자, 트럭 | 상자에 무게 숫자를 표시할 자리를 만듭니다. |
| 수학 우주정거장 | 인트 캐릭터 | 말풍선 옆에 정지 그림으로 사용합니다. |

사용한 에셋은 `assets/SOURCES.md`에 에셋 ID와 내려받기 주소를 기록합니다. 코드모스에 게시할 때 이 목록을 게시물의 사용 에셋 항목에 넣습니다.

### 새로 그리는 것

선반과 온실 배경, 물탱크, 화물칸, 해금 지도, 버튼과 아이콘을 같은 평면 벡터 그림체로 SVG로 그립니다. 분홍색 위주의 배색은 피하고, 드론 그림의 청록색과 흰색을 기준 색으로 삼습니다.

### 소리

수확, 심기, 물주기, 해금, 오류 효과음을 넣습니다. 코드모스 에셋 창고에서 먼저 찾고, 적합한 소리가 없으면 Kenney(CC0) 묶음을 사용합니다. 설정에서 소리를 끌 수 있습니다.

## 7. 기술 구조

Vite와 TypeScript를 사용하며, 화면 프레임워크는 사용하지 않습니다. 편집기는 CodeMirror 6을 사용합니다. 저장소는 `game-projects/gardener-replaced`에 독립 git 저장소로 둡니다.

코드는 네 부분으로 나누고, 각 부분은 아래 방향으로만 의존합니다.

```
ui  →  progress  →  sim
ui  →  lang      →  (sim에 주입된 드론 함수)
```

### lang: 실행기

- `lexer`: 소스 코드를 토큰으로 나눕니다. 들여쓰기를 블록 시작과 끝 토큰으로 바꿉니다.
- `parser`: 토큰으로 구문 트리를 만듭니다. 구문 오류는 줄 번호와 한국어 안내를 담아 보고합니다.
- `checker`: 구문 트리에서 잠겨 있는 문법과 함수를 찾아 실행하기 전에 보고합니다.
- `interpreter`: 구문 트리를 실행합니다. `step(틱 예산)`을 호출하면 예산만큼 실행하고 현재 줄 번호와 상태(실행 중, 완료, 오류)를 돌려줍니다.

실행기는 온실에 대해 알지 못합니다. 드론 함수는 이름, 틱 비용, 구현을 담은 목록으로 외부에서 주입합니다.

### sim: 온실 시뮬레이션

화면과 분리된 순수 로직입니다. 선반 칸, 작물 성장, 수분, 자원, 4절의 특수 규칙을 계산합니다. 시간은 `advance(밀리초)`로만 흐르고, 난수는 시드를 받는 생성기를 사용하므로 같은 입력에는 항상 같은 결과가 나옵니다.

### progress: 진행

해금 트리의 정의와 구입 처리, 안내 내용, 저장과 불러오기를 담당합니다.

### ui: 화면

편집기, 온실 그림(SVG), 해금 화면, 안내 말풍선, 설명서, 설정을 담당합니다. 프레임마다 시뮬레이션을 진행시키고 실행기에 틱 예산을 준 다음, 바뀐 상태를 화면에 반영합니다.

### 저장

- `localStorage`의 `gardener-replaced:save:v1` 키 하나에 코드, 자원, 해금 상태, 선반 상태, 플레이 시간, 설정을 저장합니다.
- 코드가 바뀌거나 해금할 때, 그리고 10초마다 저장합니다.
- 다시 열면 선반과 자원은 복원되고, 프로그램은 정지된 상태로 시작합니다.
- 저장 데이터에 버전 번호를 넣습니다. 읽을 수 없는 데이터라면 새 게임으로 시작하고, 기존 데이터는 지우지 않고 별도 키로 옮겨 둡니다.
- 설정에 "처음부터 다시 시작하기"를 두며, 누르면 확인을 한 번 받습니다. 이 게임이 만든 키만 지웁니다.

## 8. 오류 처리

| 상황 | 처리 |
|---|---|
| 구문 오류 | 실행하지 않고, 해당 줄을 표시하며 원인을 한국어로 안내합니다. |
| 잠긴 문법이나 함수 사용 | 실행하지 않고, 필요한 해금 항목의 이름을 안내합니다. |
| 실행 중 오류(없는 변수, 잘못된 자료형, 인덱스 범위 초과, 0으로 나누기) | 프로그램을 정지하고, 해당 줄을 강조하며 원인을 안내합니다. 온실 상태는 그대로 유지합니다. |
| 함수 호출이 지나치게 깊어짐(재귀 200단계 초과) | 실행 중 오류로 처리합니다. |
| 드론 함수의 실패(비용 부족, 칸이 차 있음) | 오류로 처리하지 않고 `False`를 돌려줍니다. |

## 9. 검증

- **자동 테스트(Vitest):** 실행기의 문법별 동작과 오류 안내, 틱 예산에 따른 중단과 재개, 잠긴 문법 검사, 온실의 작물별 규칙(튤립 이웃, 해바라기 보너스, 토마토 정사각형, 상자 정리 판정), 해금 구입, 저장과 불러오기를 검증합니다.
- **진행 가능성 테스트:** 각 해금 단계에서 사용할 수 있는 문법만으로 작성한 모범 코드를 시뮬레이션에 실행시켜, 다음 해금 비용을 정해진 시간 안에 모을 수 있는지 확인합니다. 이 테스트 결과를 기준으로 비용과 성장 시간을 조정합니다.
- **브라우저 확인:** 처음부터 엔딩까지 직접 진행하면서 안내 문구, 줄 강조, 무한 반복 중 정지, 새로 고침 후 복원을 확인합니다.

## 10. 배포

기존 게임과 같은 방식으로 `tools/build-artifact.mjs`를 사용하여 HTML 파일 하나로 만들고 Claude 아티팩트로 배포합니다. 코드모스 게시는 플레이 확인을 마친 뒤에 별도로 진행합니다.
